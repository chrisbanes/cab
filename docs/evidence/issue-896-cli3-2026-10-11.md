## Limits

- No runtime, model, repository or GitHub settings are offered (#826, #897).
- Bound leads without an assignment row are not in the affected list; the list is
  informational, never an apply-time fence.
- `capacity get` reuses the heavier runtime settings read
  ([#875](https://github.com/chrisbanes/ensemble/issues/875)).
- Creation is not reversible (revoke or pause instead) and adoption is one-way
  (restore as a new revision and adopt again).
- A duplicate ID applied with a fresh key from another machine is stopped only by
  the CLI's existence pre-check; the service still reports it as an unclassified
  error ([#873](https://github.com/chrisbanes/ensemble/issues/873)).
- The document digest detects accidental or in-transit modification; it is not a
  MAC against a same-user writer.
- The diff is a bounded prefix/suffix line diff, not a minimal diff.
- Lowering a limit below current usage was not exercised with live usage.
- No run from a real second machine or private transport, and no Keychain run.
