## Limits

- Propagation of `ENSEMBLE_MANAGED_ASSIGNMENT` into Codex tool shells is unproved;
  CLI8 qualifies it. The marker guards against accidental privilege crossing only and
  is not OS isolation.
- No run from a real second machine or private transport; HTTPS used a local TLS
  proxy with a throwaway certificate.
- The CLI command surface is partial: `auth`, `connection` and `task get` only.
- The Settings credential section has no `design/design.pen` frame
  ([#904](https://github.com/chrisbanes/ensemble/issues/904)); the legacy HTML UI has
  no credential controls.
