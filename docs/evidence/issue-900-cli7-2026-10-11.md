## Limits

- Supplied inputs are not the runtime's effective prompt; tool observation is
  incomplete; reasoning is not collected; process stderr is not captured.
- Direct runs and executions before this change read `not-captured`.
- Claude executions record service-admitted settings only and report runtime events
  `unsupported`.
- Exact-value redaction runs after pattern redaction, so an instruction text that
  itself contains a credential pattern (for example `token=…`) is no longer an
  exact match and is redacted only at the pattern; the remaining instruction text
  can appear in general diagnostic views. Conversation history shares this
  sanitiser behaviour.
- Retention variables apply to directly launched services; the rendered
  LaunchAgent uses the defaults.
- The quota bounds payload text only, not the database, WAL or backups.
- No second machine, private transport or Keychain run.
